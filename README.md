# EV Charging Station Finder
# Author:  Sakshi Kiran Thange

## Overview

The **EV Charging Station Finder** is a web application designed to help electric vehicle (EV) owners find nearby charging stations based on their location(especially in pune). This project combines a user-friendly interface with real-time data, allowing users to easily discover, select, and book EV charging stations.

## Features

- **Login/Signup:** Users can create an account and log in to access the application.
- **Location-based Search:** The application uses the user's location to search for nearby EV charging stations.
- **Map Integration:** A map displays available charging stations, with details like location and availability.
- **Booking System:** Users can reserve a charging station at a chosen location and time.

## Technologies Used

- **Frontend:**
  - ReactJS
  - Map API (e.g., Google Maps, Leaflet, etc.)
- **Backend:**
  - Node.js
  - Express.js
- **Database:** 
  - Firebase
